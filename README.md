# block-suggested-posts
Filter out suggested posts &amp; recommended groups on Facebook Newsfeed

**Based on Vietnamese and English Language** 

### **Installation** 
1. Make sure you have Tampermonkey extension or [click here](https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo) to add it for your browser.
> For Tampermokey to execute properly, [read more](https://www.tampermonkey.net/faq.php?q=Q209#Q209).

2. [Installation script](https://github.com/HaroldDao/block-suggested-posts/raw/main/facebook-filter.user.js).

> Everything's done, you can visit [Facebook](https://facebook.com/) and check it out.
